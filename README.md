# Bairros RJ

**Quanto você conhece o mapa do Rio?** A map game for learning the neighborhoods (_bairros_) of Rio de Janeiro — and the municipalities of Greater Rio.

▶ Play: <https://ludobegins.github.io/bairros-rj/>

## How to play

- **Digitar o nome** — a place blinks on the map; type its name (accents, case and small typos don't matter; common nicknames like "Recreio" or "Caxias" are accepted).
- **Clicar no mapa** — a name is shown; tap/click it on the map.
- **Só Rio** (167 neighborhoods) or **Grande Rio** (8 Rio neighborhoods + 2 of the 21 other Metropolitan Region municipalities per round).
- Optional zone filter: Centro, Zona Sul, Zona Norte, Zona Oeste, Zona Sudoeste.
- 10 places per round, 3 attempts each (3/2/1 points). High scores and per-place stats are kept in your browser.
- Outside a round, tap the map to see a place's name.

The map has no labels on purpose — orient yourself by streets, rail lines, beaches, lagoons and mountains.

## Development

Requires Node.js LTS (`nvm use`).

```sh
npm install
npm run dev        # local dev server (add `-- --host` to open it on your phone)
npm test           # unit tests (Vitest)
npm run lint       # ESLint + Prettier check
npm run build      # production build in dist/
npm run test:e2e   # plays full rounds in headless Firefox (needs Firefox + network)
```

Pushing to `main` runs lint, tests and build on GitHub Actions and deploys to GitHub Pages.

### Project layout

```
src/core/     game logic, no DOM (name matching, round drawing, session, storage)
src/map/      MapLibre wrapper and map styling
src/ui/       screens: menu, game, results, stats
scripts/      data pipeline (fetch + build)
data/         curated data (zones, aliases, RMRJ list) — see data/README.md
public/data/  generated places.json (TopoJSON, committed)
docs/         SPEC.md and PLAN.md
```

### Data

`public/data/places.json` is generated by `npm run data:fetch && npm run data:build`. Sources, curation rules and the processing steps are documented in [data/README.md](data/README.md).
